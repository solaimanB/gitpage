Over mij

Van idee naar werkende code, met oog voor detail.

Al van jongs af aan ben ik gefascineerd door hoe technologie problemen kan oplossen. Wat begon met het sleutelen aan simpele HTML-pagina's is uitgegroeid tot het ontwikkelen van volledige webapplicaties, open-source tools en creatieve projecten op GitHub.

Wanneer ik niet achter mijn scherm zit om code te schrijven, vind ik het leuk om nieuwe technologieën te verkennen, bij te dragen aan open-source communities en te genieten van een goede kop koffie.

Technologieën waar ik graag mee werk:

HTML5 & CSS3 JavaScript (ES6+) TypeScript React / Next.js Tailwind CSS Node.js Python Git & GitHub
